Control Statements

Introduction
Control Statements are used to control the flow of execution of a program.
Normally, Python executes statements one after another from top to bottom. Control
statements allow the program to make decisions, repeat tasks, or alter the normal flow of
execution based on specific conditions.
Control statements help the program decide:
● Which code should execute
● When code should execute
● How many times code should execute
● Whether execution should continue, stop, or skip
Types of Control Statements
Python control statements are broadly classified into three categories:
Type Purpose
Conditional Statements Execute code based on conditions
Looping Statements Execute code repeatedly
Jump Statements Alter the normal flow of loops

Why Control Statements Are Important
Control statements help programs:
● Make decisions
● Repeat tasks efficiently
● Avoid unnecessary code repetition
● Handle different situations dynamically
● Control program execution flow
Without control statements, programs would execute sequentially and could not respond
intelligently to different inputs or situations.

11. How for Loop Works Internally
This is very important for understanding Python.
Consider:
l = [1, 2, 3, 4]

for i in l:
    print(i)
Conceptually, Python performs something similar to:
iterator = iter(l)

while True:
    try:
        i = next(iterator)
        print(i)
    except StopIteration:
        break
Important roles
iter()
   ↓
creates iterator

next()
   ↓
gets next value from iterator

for loop
   ↓
automatically performs this process
So the programmer does not need to manually call iter() and next() when using a for loop.
Python's for machinery handles it internally.

26. Example with Statements Outside the if
Consider:

    if i % 2 == 0:

end of if
end of if
4
end of if
end of if
end of loop
Why?
print("end of if") is outside the if block but inside the for loop.
Therefore it executes for every iteration.
The structure is:
for
│
├── if
│   └── print(i)
│
└── print("end of if")
Whereas:

    if i % 2 == 0:
        print(i)
        print("end of if")

print("end of loop")
Here "end of if" executes only when the number is even.

28. Most Important Interview Questions
Q1. What is an if statement?
An if statement is used to execute a block of code when a specified condition is True.
Q2. What is elif?
elif means else if. It is used to check additional conditions when the previous condition is false.
Q3. What happens when an if condition is true?
Its corresponding block executes, and the remaining elif/else blocks in that chain are skipped.
Q4. What is nested if?
An if statement written inside another if statement is called a nested if.
Q5. What is a loop?
A loop is used to repeatedly execute a block of code.
Q6. What are the two main loops in Python?
1. for loop
2. while loop
Q7. What is range()?
range() creates a range object representing a sequence of numbers.
Q8. Is the stop value included in range()?
No. The stop value is excluded.
range(1, 5)
produces:
1 2 3 4
Q9. What does iter() do?
iter() obtains an iterator from an iterable.
Q10. What does next() do?
next() retrieves the next value from an iterator.
Q11. What happens when an iterator has no more values?
It raises:
StopIteration
Q12. Does the programmer manually call next() in a normal for loop?
No. The for loop internally obtains an iterator and repeatedly requests the next value until the iterator is exhausted.
